# Website and repository organization — 23 October 2026

## Scope

The public website is now in `website/` (formerly `website-rewrite/`). The supported HMIS remains in `platform/`, with no source changes. The root Node/SQLite compatibility pilot and its deployment files have moved together to `legacy/`. Root documentation, npm shortcuts and the multi-folder editor workspace identify each application explicitly. CI has independent website, platform and legacy jobs.

## Patient experience

- Shorter responsive introduction, clear directions/enquiry actions, five primary navigation links and fixed mobile patient actions.
- Compact cookie notice with the existing three equal choices, expiry, withdrawal and browser-privacy handling.
- Five practical homepage FAQs, plus the current full patient FAQ page. Blog, partnerships, staff access and careers remain reachable through the footer.
- Services, contact content, the registration date and Kenya clock reconciled against the public live pages. Service links select the corresponding enquiry option. The selected service is validated and saved in the existing message text, preserved on errors, and included in duplicate-request checks; no database migration is required.
- Confirmed totals remain 6,255 patients and 13,557 encounters dated 27 September 2026. Registration remains 27 September 2022. The totals reporting-date selector explicitly targets the totals heading, avoiding the registration date.

## Efficiency

- Homepage CSS consolidated from nine live stylesheet links into one fingerprinted bundle; other source pages use a shared bundle. Editable source CSS remains in `site/assets/`; `npm run website:build` regenerates bundles and references deterministically without dependencies.
- System fonts replace the Google Fonts CSS import, eliminating external font requests.
- The displayed wordmark uses a lossless WebP derivative: 141,539 → 38,894 bytes (72.5% smaller). The original PNG remains available for sharing and existing consumers.
- News, ratings and care totals fetch as their sections approach the viewport, with immediate fallback in browsers lacking IntersectionObserver. Dated/static content and links remain when APIs or scripts are unavailable.
- The Kenya clock refreshes every minute, pauses while the document is hidden, and resumes on return.
- Apache compression and long-lived caching apply to static files only. Fingerprinted CSS can be cached immutably; private PHP responses retain no-store behavior. Hosting support must be verified after deployment. These are source/request reductions, not measured field-speed or Lighthouse results.
