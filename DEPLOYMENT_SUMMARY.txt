SUPPORT & TROUBLESHOOTING
================================================================================

If CSS won't load:
  - Verify file path: /css/style.css
  - Check file permissions: chmod 644
  - Clear browser cache

If JavaScript won't work:
  - Check browser console for errors
  - Verify main.js exists
  - Clear cache

If images are missing:
  - Verify /assets/ folder uploaded
  - Check image paths are relative
  - Verify permissions: chmod 755

If forms won't submit:
  - Check form action URLs
  - Verify backend endpoints (if applicable)
  - Check browser console

For more help:
  - See QUICK_DEPLOYMENT_CHECKLIST.md (Troubleshooting section)
  - Contact your hosting provider
  - Check Safaricom/Firebase/GitHub documentation

Emergency Rollback:
  git reset --hard HEAD~1
  git push --force origin main
