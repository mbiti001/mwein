## 🆘 Troubleshooting Quick Links

| Problem | Solution |
|---------|----------|
| Backend won't start | Check Node.js installation, run `node --version` |
| Port 3000 in use | Kill process or change PORT in .env |
| CORS errors | Verify backend URL in js/main.js |
| Login fails | Register admin account first |
| No analytics data | Ensure tracker is loaded on pages |
| Database locked | Restart server, check file permissions |
| Safaricom says no Node.js | Use Firebase/Vercel alternative |

**See BACKEND/DEPLOYMENT_GUIDE.md → "Troubleshooting" for more help**
