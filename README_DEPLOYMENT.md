## 💡 3 Easy Deployment Options

### Option A: Safaricom cPanel

```bash
1. Log into cPanel
2. Use File Manager to upload all files
3. Set permissions: 644 for files, 755 for directories
4. Verify HTTPS is configured
5. Test: Visit https://mweinmedical.co.ke
```

**Time:** 30 minutes  
**Cost:** Monthly hosting fee

---

### Option B: Firebase (Recommended for Beginners)

```bash
npm install -g firebase-tools
firebase init hosting
firebase deploy
```

**Time:** 15 minutes  
**Cost:** Free tier available  
**Bonus:** Automatic SSL, global CDN, fast deployment

---

### Option C: GitHub Pages (Simplest)

```bash
git push origin main
# Enable Pages in GitHub Settings
# Done!
```

**Time:** 5 minutes  
**Cost:** Free forever  
**Note:** Static site only

## 🆘 If Something Goes Wrong

**CSS won't load?**
```bash
# Check file exists: /css/style.css
# Check permissions: chmod 644 css/style.css
# Clear browser cache: Ctrl+Shift+Delete
```

**Images missing?**
```bash
# Check paths are relative (not absolute)
# Verify /assets/ folder uploaded
# Check permissions: chmod 755 assets/
```

**Quick recovery:**
```bash
git reset --hard HEAD~1
git push --force origin main
```
